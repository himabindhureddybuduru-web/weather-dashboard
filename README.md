# 🌦️ Weather Dashboard

### Thiranex Virtual Internship - Task 4 (Web Development)

A responsive **Real-Time Weather Dashboard** developed as part of **Task 4 of the Thiranex Web Development Internship**.

This project demonstrates the use of **Asynchronous JavaScript, RESTful APIs, Fetch API, and JSON data processing** by fetching live weather information from the **OpenWeatherMap API**.

Users can search weather by city name, view current weather conditions, check a 5-day forecast, and get weather information automatically using their current location through the **Browser Geolocation API**.

#  API Configuration

This project uses the OpenWeatherMap API.

### Steps:

1. Create an account on OpenWeatherMap.
2. Generate an API key.
3. Open `script.js`.
4. Replace:

```javascript
const API_KEY = "YOUR_API_KEY";
```

with:

```javascript
const API_KEY = "YOUR_ACTUAL_API_KEY";
```

> Note: Newly created API keys may take some time to activate.
